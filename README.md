## 🌟 Overview

Welcome to my official interactive video portfolio codebase! Designed and built with modern web technologies, this portfolio showcases my technical skills in ethical hacking, full-stack web application development, privacy tools, and AI-driven platforms.

### ✨ Key Features

- 🎥 **Interactive Video Hero Section**: Immersive background video with automated unmuted playback, exact 2-repeat loop tracking, auto-pause logic, and lower-right sound & playback toggle controls.
- 🔐 **Cybersecurity Encrypt Buttons**: Custom Originkit `EncryptButton` component with real-time hacker text-scrambling and decryption animations on hover.
- 💎 **Frosted Glass Moving Gradient Resume Button**: Originkit `MovingGradientButton` featuring continuous conic gradient border motion and glassmorphic backdrop blur (`backdrop-blur-xl`).
- 🏹 **Arrow Reveal Project Links**: Originkit `ArrowRevealButton` for project repository links with dual-arrow sliding hover effects.
- 📸 **Animated Social Link Badges**: Vector SVG icons for GitHub, LinkedIn, Twitter/X, and Instagram with spring and rotation micro-animations.
- 💻 **Interactive Projects Showcase**: Categorized project filter pills (Cybersecurity, Privacy, Web Dev, AI) with responsive card grids.
- 📬 **Direct Contact & Resume Access**: Fast contact submission form with permission consent toggle and downloadable PDF resume.

## 💻 Local Setup & Development

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BlackVenom7405/Portfolio..git
   cd Portfolio.
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
